# Voxera demo rehearsal

This script rehearses the journeys available in the current browser prototype. It does not represent a production AI or multi-device flow.

1. Start the local server and open the displayed address. Choose **Organiser view** in the top-right menu.
2. On the Dashboard, show active Programmes, attendance, the upcoming sessions, and participants who could use a follow-up.
3. Open **Programmes**. Use **New Programme**, enter “Digital Skills for Work — October”, choose Online, add a short description, and create it.
4. Switch to **Participant view**. Open **Discover** and apply to **Digital Skills for Work**. Show the application confirmation.
5. Return to **Organiser view**. Open **Live Class** and start the simulated session. Point out the participant presence panel, then end the session.
6. Open **Attendance** and select **Mark present**. CSV export downloads the sample attendance rows.
7. Open **Follow-Up** and select **Run follow-up now**. Switch to the participant and open **Messages** to see the AI-labelled check-in. Reply: “I was sick, I will come next time.”
8. Return to organiser **Staff Inbox**. Review the transport hardship case, its AI translation and summary, then send the suggested reply or close the case. Open **AI-resolved** to review handled examples.
9. In participant view, open **My Programmes** and select **Watch recording**. The sample player shows the 70% threshold and quiz unlock state.
10. Return to **Reports** to show attendance modes and absence reasons. Open **Settings → Reset demo data** to restore the starting state.

To rehearse the voice confirmation, switch to the participant, tap the central microphone, and allow microphone access if prompted. A placeholder Yoruba transcript appears with **Confirm**, **Edit text**, and **Record again**. The prototype does not yet run speech recognition or translation models.
